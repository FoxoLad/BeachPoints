# BeachPoints

Mobile-first web app for a beach-side bottle drop: scan a personal QR (or tap RFID later), earn store credit, and redeem at partner shops.

## Run

```bash
npm install
npm run dev
```

Accounts live in the browser (`localStorage`). Email sign-in uses a demo one-time code shown on screen — Gmail / Hotmail / Outlook shortcuts are included. Use **Preview as Alex** to see a 230-point account that matches the mockups.

## Client features

- Individual sign-in with first and last name
- Personal QR payload the bin can credit
- Store rewards and partner strip
- Waste count, kg diverted, and a board that steps every 12 bottles (inside the 10–15 range)
- Bronze / Silver / Gold / Diamond
- Large points on Home
- Reminder sheet with balance + motivational copy
- Collection and redemption history
